Sobre mí

Trabajo principalmente en software de gestión para PyMEs: los sistemas que llevan el stock, la caja, la facturación y el personal de un negocio real. Es un dominio donde el detalle importa — un redondeo mal hecho o un estado de pedido inconsistente se nota al día siguiente en la operación.

Mi foco está en el backend y el modelo de datos: esquemas relacionales bien normalizados con PostgreSQL y Prisma, APIs REST con validación estricta, control de acceso por roles y trazabilidad de cada movimiento. Del lado del cliente trabajo con React y Next.js, priorizando interfaces densas en información pero legibles.

También me interesa la seguridad y la automatización: escribí una herramienta de auditoría de hardening sobre Nmap y bots de monitoreo que corren desatendidos con logging rotativo y alertas por Telegram.

  • Foco Backend · Modelo de datos · Integraciones
  • Dominio ERP, inventario, facturación, POS
  • Integraciones AFIP · Mercado Pago · Twilio · AWS Rekognition
  • Idiomas Español (nativo) · Inglés técnico

KardexGo

Sistema multi-tenant de inventario con marketplace B2B

Plataforma SaaS donde cada empresa opera su propio inventario aislado y, además, puede conectarse con otras: los mayoristas publican catálogo y los minoristas hacen pedidos con stock en espejo que se sincroniza automáticamente. Incluye workflow de pedidos con estados (DRAFT → PENDING → CONFIRMED → SHIPPED → DELIVERED), RBAC de cuatro niveles, alertas de stock bajo por WhatsApp, facturación AFIP y audit trail completo de cada movimiento.

  • Aislamiento multi-tenant a nivel de esquema con Prisma
  • Colas con Bull + Redis para sincronización y notificaciones
  • Reportes de BI con Recharts y exportación a Excel

Audit Script

Auditoría de hardening pre-producción

Herramienta de línea de comandos que audita la superficie expuesta de un servidor antes del pasaje a producción: escanea puertos y versiones de servicios, evalúa los cifrados SSL/TLS, revisa cabeceras de seguridad HTTP y detecta directorios y archivos sensibles filtrados (.env, volcados SQL).

  • Orquesta Nmap (-sV, ssl-enum-ciphers, http-security-headers, http-enum)
  • Parseo del XML por streams para no cargar el reporte completo en memoria
  • Salida estructurada en JSON, apta para pipelines de CI
  • Node.js
  • Nmap
  • fast-xml-parser
  • Express
  • Socket.IO
